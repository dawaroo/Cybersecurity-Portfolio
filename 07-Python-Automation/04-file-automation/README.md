# File Automation (Python Automation)

## Overview
This project demonstrates basic file automation tasks using Python.

The script creates a file, writes security-related information to it, and then reads the file contents to verify the update.

## Security Relevance
Automating file operations is essential in cybersecurity for maintaining logs, updating configuration files, and managing access control data.

## What the Script Does
- Creates or overwrites a text file
- Writes security-related data to the file
- Reads the file content
- Displays the stored information

## Skills Demonstrated
- File handling using Python
- Writing and reading text files
- Basic automation workflows
