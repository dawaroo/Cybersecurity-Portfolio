# IP Validation (Python Automation)

## Overview
This project validates IP addresses to ensure they follow the correct IPv4 format before being used in security controls such as allow lists or log analysis.

The script focuses on basic string manipulation and conditional logic to identify valid and invalid IP addresses.

## Security Relevance
Validating IP addresses helps prevent incorrect or malformed data from being applied to security rules, which could lead to misconfigurations or access control errors.

## What the Script Does
- Takes a list of IP addresses
- Checks if each IP follows the IPv4 format
- Separates valid IP addresses from invalid ones
- Displays the results

## Skills Demonstrated
- String manipulation
- Conditional logic
- Loops
- Input validation concepts for security automation
