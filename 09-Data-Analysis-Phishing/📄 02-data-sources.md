# Data Sources

## Selected Dataset
**Phishing URLs Dataset with Extracted Features**
- Source: Kaggle (user: victusadi)
- Contains: URL, label (phishing/benign), URL length, dot count, HTTPS presence, IP presence, subdirectories, parameters, suspicious words, TLD, special characters, digit count, entropy.

## Alternative Dataset Consulted
**Phishing Websites Dataset**
- Source: Kaggle (based on the UCI Machine Learning Repository)
- Contains additional features on HTTPS certificates (certificate authority, certificate age) and subdomain count.

## Why This Dataset Was Chosen
It's a clean, well-structured dataset with columns that directly match the data elements identified in Step 2, making it appropriate for a first analysis project (module 1 - fundamentals).
